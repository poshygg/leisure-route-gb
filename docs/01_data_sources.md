# 데이터 인벤토리 (검증됨)

각 항목은 실제로 확인한 것만 적었습니다. **함정** 표시는 반드시 읽으십시오.

## 특징용 데이터

### 임상도 — A1, A2
- 산림청 산림공간정보, **1:5000** (또는 1:25000)
- 속성: `임종` `임상` `수종` `경급` `영급` `수관밀도`
- `임상` = **침엽수림 / 활엽수림 / 혼효림 / 죽림** ← A1·A2가 이 필드에서 바로 나옵니다
- 취득: 산림공간정보서비스 → 주제도 보기 → 다운로드 **무료신청** → 승인 → SHP
- ⚠️ **함정**: 즉시 다운로드가 아니라 신청·승인 절차입니다. 일정에 반영하십시오.
  급하면 1:25000을 먼저 쓰십시오. 1:5000은 시군 단위로 잘라 받습니다.

### 토지피복지도 — A5, Z1, Z2
- 환경부 환경공간정보. **대분류 7 / 중분류 22 / 세분류 41**
- 분류코드는 법령 별표 "토지피복지도 분류코드 및 색상표준"에 있습니다
- 세분류로 공업지역·인공나지·자연초지·인공초지가 직접 구분됩니다

### 국가유산 공간정보 — B1, B2, B3
- `data.go.kr` 3070426 — **OpenAPI(XML) + SHP** 둘 다 무료, 약 15,000종
- **폴리곤**(면적·규제범위)을 줍니다. 점이 아니라 면이라 "길에서 보이는가"를 계산할 수 있습니다
- 대분류 확인됨: 유적건조물 / 기록유산 / 유물 / 무형유산 / 자연유산 / 등록문화유산
- ⚠️ **미확인**: 사찰·석탑·성곽 수준의 **중·소분류 필드가 SHP에 실제로 있는지 확인 안 됐습니다.**
  없으면 **B1~B3을 하나로 합쳐야 합니다.** 착수 전 첫 번째로 확인할 항목.
- ⚠️ **좌표계**: `.prj` 먼저 확인. 국내 TM 계열이면 EPSG:5179로 변환
- ⚠️ **폴리곤 유무**: 15,000종 전부가 면은 아닐 수 있습니다. geometry type 분포를 세고,
  점만 있는 건 등급별 고정 반경(사적 200m / 보물 50m)으로 폴백

### 가로수길 표준데이터 — A6
- `data.go.kr` 15021145, 171개 지자체, 연 1회 갱신
- 컬럼: `가로수길명` `시작위도/경도` `종료위도/경도` `가로수종류` `가로수수량` `가로수길길이` `식재연도`
- ⚠️ **함정 3개**:
  1. 좌표가 **시작·종료 2점뿐** — 선형은 도로망에 스냅해야 합니다
  2. `가로수종류`가 **콤마 다중나열** (`"황금메타세쿼이아, 벚나무, 미국풍나무, 산딸나무"`)
     이고 `가로수수량`은 길 전체 합계라 **수종별 배분이 불가능**합니다
  3. 표기 비통일: 왕벚나무 / 벚나무 / 벛나무(오타) / 메타세쿼이아 / 메타세콰이아 / 메타세쿼이어
     → **정규화 사전 필수**
- ⚠️ 등록 기준이 "꽃"이 아니라 "특색"이라 은행나무·느티나무·메타세쿼이아가 대거 포함됩니다.
  개화종 화이트리스트로 걸러야 비로소 꽃길입니다. (전국 가로수 823만본 중 개화종은 상위 5종 기준 약 32%)
- 보완: 지자체별 **가로수 현황(공간정보)** 은 나무 한 그루 단위 point + 수종코드. 커버리지는 듬성듬성

### 전국공공미술및조형물표준데이터 — B5
- `data.go.kr` 15129443. `작품명` `작품유형` `규격` `소재지도로명주소` `관리기관명`
- ⚠️ **좌표 없음, 주소만** → 지오코딩 필요
- 보완: 건축물미술작품 DB (1988~2024, 설치일자·작가·건축물용도), 공공미술포털

### 전국지역특화거리표준데이터 — B6
- `data.go.kr` 15017322. 문화예술 테마거리 / 음식 특화거리 / 디자인 거리 등
- ⚠️ **좌표 없음, 주소만** → 지오코딩 필요

### 하천·호소 / 해안선 — A3, A4
- OSM `waterway`, 국가하천망. 해안선은 국토지리정보원 수치지형도
- ⚠️ A4는 해파랑길이 정의상 전 구간 해안 인접이라 **표준편차가 작아 변별력이 없을 수 있습니다.**
  실제 분포 보고 채택 판단 (내연산 등 내륙 우회 구간은 구별하므로 일단 유지)

### 도로망 — Z3
- OSM `highway` 위계, 또는 국토지리정보원 연속수치지형도 도로중심선

### DEM 5m — D1, D2 (v1 미사용이나 미리 계산)
- 국토지리정보원 수치표고모델
- **v1 축에 없어도 계산해서 컬럼에 저장하십시오.** DEM을 이미 읽으니 추가 비용이 거의 없고,
  축 D를 켜는 순간 바로 씁니다

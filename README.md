# 여유로운 길 (Leisure Route) — 경북

> 목적지까지 가는 길 중에서, **가장 여유로운 길**을 골라주는 보행 경로 추천.

최단 거리 대신 "여유로움"이 최대인 경로를 찾습니다. 공공데이터로 도로 구간마다 점수를 매기고,
지정 명승·국가숲길 같은 **앵커**로 그 점수가 맞는지 검증하고, 사용자에게는 숫자가 아니라
**"숲길 · 벚꽃길 · 문화재길"** 같은 라벨과 뷰포인트로 보여줍니다.

```
cost(e) = length(e) / (1 + λ · A(e))
제약    : length(route) ≤ β · length(shortest)
```

---

## 축 구조

점수를 **축(axis)** 단위로 묶습니다. 사용자는 축을 고르고, 감점 축은 항상 적용됩니다.

```
선택 축 (사용자가 고름)
  축 A  자연친화        A1~A6
  축 B  역사문화        B1~B6

상시 축 (선택과 무관)
  축 Z  감점            Z1~Z3

예약 축 (v1 미사용, 행만 추가하면 켜짐)
  축 C  정온     축 D  보행편의     축 E  조망     축 F  계절

최종 점수 = (선택된 축 점수) + (축 Z 감점)
```

**축 Z는 끌 수 없습니다.** 끄면 자연친화 모드로 공단 옆길을 추천받습니다.

### 축 A — 자연친화

| # | 특징 | 부호 | 데이터 | 계산 |
|---|------|:---:|--------|------|
| A1 | 활엽수림 면적비 | + | 임상도 `임상` | `area_ratio` |
| A2 | 침엽수림 면적비 | + | 임상도 `임상` | `area_ratio` |
| A3 | 하천·호소 근접도 | + | 하천·호소 폴리곤 | `proximity` |
| A4 | 해안 근접도 | + | 해안선 | `proximity` |
| A5 | 초지 비율 | **−** | 토지피복 세분류 | `area_ratio` |
| A6 | 화목 비율 | + | 가로수 `가로수종류` | `area_ratio` |

**A1·A2를 나눈 이유**: 활엽수는 단풍 잠재력(축 F에서 재사용), 침엽수는 상록. 합치면 계절 축을 만들 때 다시 쪼개야 합니다.

**A5가 음수인 게 핵심**입니다. 잔디밭·초지는 나무가 아니고 미관을 깎습니다. 이걸 빼면 NDVI 방식의 오류를 반복합니다.

### 축 B — 역사문화

| # | 특징 | 부호 | 데이터 | 계산 |
|---|------|:---:|--------|------|
| B1 | 건축물형 유산 (사찰·서원·향교·고택) | + | 국가유산 | `count_weighted` |
| B2 | 석조물형 유산 (석탑·석불·비석) | + | 국가유산 | `count_weighted` |
| B3 | 유적형 (성곽·읍성·고분) | + | 국가유산 | `count_weighted` |
| B4 | 전통마을 근접도 | + | 민속마을·한옥 지정 | `proximity` |
| B5 | 공공조형물 개수 | + | 공공미술및조형물 | `count_weighted` |
| B6 | 지역특화거리 포함 | + | 지역특화거리 | `presence` |

등급가중(B1~B3): 국가지정 : 시도지정 : 등록 = **2 : 1.5 : 1**

### 축 Z — 감점 (상시)

| # | 특징 | 부호 | 데이터 |
|---|------|:---:|--------|
| Z1 | 공업지역 면적비 | − | 토지피복 세분류 |
| Z2 | 인공나지 면적비 | − | 토지피복 세분류 |
| Z3 | 간선도로 근접도 | − | 도로망 (등급 필터) |

**합계 15개** (A6 제외 시 14개)

## 계산 방식은 4개뿐입니다

축 A·B·Z 전체가 함수 4개로 끝납니다 → [`src/leisure_route/scoring/methods.py`](src/leisure_route/scoring/methods.py)

| 함수 | 의미 |
|------|------|
| `area_ratio` | 버퍼 내 해당 폴리곤 면적 / 버퍼 전체 면적 |
| `count_weighted` | 버퍼 내 점 개수 (등급 가중 가능) |
| `proximity` | 최근접 거리 → `1/(1+d/d0)` 감쇠 |
| `presence` | 포함 여부 0/1 |

축 C~F는 새 함수(`noise_decay`, `slope_mean`, `viewshed`)가 필요해서 v1에서 뺐습니다.

## 특징은 코드가 아니라 테이블입니다

축 추가가 **행 추가**가 되도록 [`config/features.csv`](config/features.csv)에 정의를 둡니다.
코드에 하드코딩하지 마십시오.

## 계산층 / 표시층

| 층 | 형태 | 용도 |
|----|------|------|
| 계산층 | 연속값 (`0.62`) | 경로 최적화, 순위, AUC 검증 |
| 표시층 | 명사 라벨 (`숲길`) | 사용자에게 보여주기 |

**표시층은 계산층에서 임계값으로 자동 유도됩니다** → [`config/display_rules.csv`](config/display_rules.csv)

```
활엽수 면적비 0.62  →  > 0.5    →  🌲 숲길
화목 비율 0.15      →  > 0.1    →  🌸 벚꽃길
하천 최근접 80m     →  < 200m   →  🌊 강변길
```

연속값이 먼저 있어야 하는 이유:
1. **변별력** — 이진 라벨이면 수십 구간이 동점이 되고 순위가 안 매겨집니다
2. **임계값을 정하려면 분포를 봐야** 합니다. 이진화는 그 다음 단계입니다
3. **뷰포인트** — 국소 최댓값 지점을 찾아야 하는데, "있음/없음"만 알면 어디 찍을지 모릅니다

## 뷰포인트

경로 위에 📍를 찍고 라벨을 붙입니다. 두 종류:

- **이미 점인 것** (B1~B3, B5) → 그대로 사용
- **면·선에서 뽑는 것** (A1~A4, A6) → 50m 소구간으로 쪼개 **국소 최댓값** 지점에 찍기

부수 효과로 알고리즘이 쉬워집니다: 엣지 보상(Arc Orienteering) → **점 보상(Orienteering)** 이 되어
탐욕 삽입이 "다음에 어느 뷰포인트를 넣을까"로 단순해집니다.

## ⛔ 누출 방지 — 앵커는 특징에 넣지 마십시오

| 데이터 | 역할 | 특징 사용 |
|--------|------|:---:|
| 명승 지정 | 앵커 (등급 3) | ❌ |
| 국가지질공원 지질명소 | 앵커 | ❌ |
| 도립·군립공원 경계 | 앵커 (등급 2) | ❌ |
| 국가숲길 지정 | 앵커 | ❌ |
| 그 외 지정유산 (사찰·석탑·성곽) | 특징 | ✅ |

**국가유산 데이터를 받으면 종목코드로 명승을 먼저 분리하십시오.** 명승은 앵커 파일로,
나머지는 특징 파일로. 섞으면 AUC가 조용히 무의미해집니다.

**추가 주의 — 두루누비도 앵커입니다.** 해파랑길이 보경사를 지나가도록 설계됐다면 B1은
앵커 정보를 일부 담습니다. 완전 분리는 불가능하니:
- 학습은 두루누비, 검증은 명승·공원으로 **앵커를 두 벌로 분리**
- 또는 **지역 홀드아웃** (경주 학습 → 영덕 검증)

## 시작하기

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
cp .env.example .env      # data.go.kr 서비스키 입력
```

```bash
python scripts/02_build_graph.py  --region gyeongju
python scripts/03_score_edges.py  --region gyeongju --axes A,B,Z
python scripts/04_route_demo.py   --region gyeongju --from 35.8562,129.2247 --to 35.8348,129.2194
```

## 로드맵

| 단계 | 내용 | 게이트 |
|------|------|--------|
| 1 | 경주 1개 시군 OSM 보행 그래프 | 엣지 수·연결성 |
| 2 | 축 A·B·Z 15개 특징 스코어링 | 분포가 상식적인가 |
| 3 | 고정 가중치 라우팅 → **눈으로 검증** | ★ **하드 게이트** |
| 4 | 앵커로 AUC 검증 | 명승·공원 구간이 상위에 오는가 |
| 5 | 표시층 임계값 튜닝 + 뷰포인트 | 상위 20~30%가 라벨 받게 |
| 6 | 축 C~F 추가, 시군 확대 | |

3단계에서 "오 이 길 좋네"가 안 나오면 데이터를 더 넣어도 안 됩니다 (대개 OSM 보행로 누락).
